**Sruthi 0.4.1: now free software under the GPL.**

- **GPL-3.0-or-later.** Sruthi is now licensed under the GNU General Public License v3 or later. You can use it, study it, change it and share it. If you distribute a modified version, you must share its source under the same license. Versions 0.4.0 and earlier were released under MIT and stay available under it.
- **A short contributor agreement.** CONTRIBUTING.md now explains what contributors agree to, and pull requests carry a checkbox for it.
- **Tidy-ups.** The Rust sources are formatted, and the README and website describe the new license.

Everything from 0.4.0 is included: history across days with a day wheel and heat calendar, shareable stats cards, send after pasting, audio storage controls, snippets and the learning dictionary.

Windows is the primary platform. The macOS build is unsigned (right-click the app and choose Open on first launch) and the app-aware features need Windows. The Windows installer is not code-signed, so Windows may show "Windows protected your PC"; choose More info, then Run anyway.
