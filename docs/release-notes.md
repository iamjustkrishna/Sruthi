**Sruthi 0.4.5: the splash on every launch.**

- **Splash every time you open Sruthi.** The animated welcome now plays each time the app starts, and again when you bring the window back from the tray. It fades out by itself after about four seconds, or skip it with a click, Esc, Enter or Space. A first run still flows from the same splash into setup.
- **No flash of Home.** The splash is on screen from the first moment, so the app never shows Home before it.
- **Finer type.** The wordmark uses Segoe UI Variable's display cut with tighter spacing, and the tagline is small, tracked capitals.

Everything from 0.4.4 is included: buttons no longer turn dark on hover. And from 0.4.3: first-run setup with a PC check and model recommendation, Run setup again, models limited to what your system can run, and the My month and All time share cards.

Windows is the primary platform. The macOS build is Apple Silicon only and unsigned (right-click the app and choose Open on first launch), and the app-aware features need Windows. The Windows installer is not code-signed, so Windows may show "Windows protected your PC"; choose More info, then Run anyway.
