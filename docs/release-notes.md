**Sruthi 0.4.4: buttons no longer go dark on hover.**

- **Hover fixed everywhere.** One shared rule used to paint every button without its own hover style the same dark grey, so pale chips, links, segmented buttons, Skip and Back, the close button and the blue setup buttons all turned blackish under the pointer. Hover now lays a faint wash over the button's own colour and fades in: filled buttons lift slightly, plain ones get a light tint, selected chips and links stay blue and deepen a little. Light and dark themes both covered.

Everything from 0.4.3 is included: first-run setup with a PC check and model recommendation, Run setup again, models limited to what your system can run, and the My month and All time share cards.

Windows is the primary platform. The macOS build is Apple Silicon only and unsigned (right-click the app and choose Open on first launch), and the app-aware features need Windows. The Windows installer is not code-signed, so Windows may show "Windows protected your PC"; choose More info, then Run anyway.
